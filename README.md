# Personal Portfolio Website

A responsive personal portfolio for a student developer, built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout for mobile and desktop
- About, skills, projects, and contact sections
- Mobile navigation toggle
- Project cards and GitHub/LinkedIn links
- Automatically updates the copyright year

## Run locally
Open `index.html` in your browser. No build tools are required.

## Before publishing
1. Replace `Your Name` and the sample bio with your own details.
2. Update email, GitHub, and LinkedIn links.
3. Keep only the skills you can confidently discuss.
4. Replace project links with your actual repositories.
5. Deploy with GitHub Pages or another static hosting service.
